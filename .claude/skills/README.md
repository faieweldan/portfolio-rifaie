# Vendored design skills

Two third-party skills, both MIT-licensed, vendored so any agent working in
this repo picks up the same anti-generic-design rules.

| Skill | Source | Use for |
| --- | --- | --- |
| `hallmark` | https://github.com/nutlope/hallmark | Building new pages, redesigns, design audits. Its `references/motion.md`, `anti-patterns.md`, and `typography.md` are the working references for this portfolio's redesign. |
| `avoid-ai-design` | https://github.com/funboy322/avoid-ai-design | Auditing existing components for AI design tells and rewriting them. Has a detection-only mode. |

Original LICENSE files are kept alongside each skill.
